# Next-Rapier-avdvplus

Version **futuriste** de la skin Rapier pour **Kodi 21 Omega** sous **CoreELEC avdvplus**
(Ugoos AM6B+ / S922X) : noir profond, néons rouges, lignes géométriques nettes.

- Identifiant : `skin.next-rapier.avdvplus`. S'installe à côté de `skin.rapier.avdvplus`, avec des réglages indépendants.
- Base : [Rapier avdvplus](https://github.com/stefxg/skin.rapier.avdvplus) 21.0.21. Toutes les fonctions avdvplus sont conservées :
  logos HDR et Dolby Vision, panneau de process info, codecs audio, vue Mur, panneaux étendus.
- Skin d'origine : Rapier de **Scarfa et Gade**, https://github.com/gade01/Rapier.
- Licence : Creative Commons BY-NC-SA 3.0. Usage personnel, non commercial.

## Installation et mises à jour
La skin est publiée dans le dépôt Kodi **stefxg** (`repository.stefxg`), le même que Rapier avdvplus :
Extensions > Installer depuis un dépôt > stefxg > Habillages > Next-Rapier-avdvplus.

## Outils (`_tools/`)
Les mêmes outils que Rapier avdvplus (contrôle des XML, zip, dépôt Kodi, réglages par défaut).
`publish_repo.py` publie la skin dans la branche `repo` de stefxg/skin.rapier.avdvplus sans toucher aux autres add-ons.
